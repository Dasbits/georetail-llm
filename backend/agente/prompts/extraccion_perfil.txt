Extrae un perfil estructurado del negocio a partir del texto del usuario.
Devuelve SOLO un JSON válido, sin texto adicional, sin bloques de código.

Campos del JSON:
- sector: tipo de negocio (string)
- cliente_objetivo: objeto con edad (rango string), genero (masculino/femenino/mixto), renta (baja/media/alta)
- ticket_medio_min: precio mínimo por cliente en euros (integer)
- ticket_medio_max: precio máximo por cliente en euros (integer)
- m2_min: metros cuadrados mínimos necesarios (integer)
- m2_max: metros cuadrados máximos (integer)
- competencia_radio_metros: radio en metros para evitar competencia directa (integer, default 300)
- variables_prioritarias: lista de strings con las variables más relevantes para este negocio
  Valores posibles: flujo_peatonal, perfil_demografico, transporte, seguridad, competencia,
  actividad_comercial, turismo, zonas_verdes, aparcamiento
- es_negocio_local: true si necesita un local físico, false si es online o no aplica

Ejemplos:

INPUT: "quiero abrir una barbería para hombres jóvenes, precio asequible, zona céntrica"

INPUT: "cafetería de especialidad, clientela adulta profesional, zona de oficinas"

INPUT: "tienda de ropa deportiva, clientes jóvenes activos, precio medio"
